---
title: Built-in themes
description: Classic, Modern and Technical.
---

MDLeaf has three themes. They differ only in fonts, colours and spacing; the page structure is the same.

| Theme         | Character                                                                                                                          |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Classic**   | A word-processor look: Source Serif 4 at 11 pt, bold serif headings, thin grey table rules, dark blue links.                       |
| **Modern**    | Inter at 10.5 pt with semibold headings on a larger scale, a green accent, shaded table header rows and a coloured rule on quotes. |
| **Technical** | Compact Inter with JetBrains Mono code, bordered code blocks and zebra-striped tables with a monospace header.                     |

All three fonts are bundled with MDLeaf and work offline. Your own themes can use them by name: `"Source Serif 4 Variable"`, `"Inter Variable"` and `"JetBrains Mono Variable"`.

To start your own theme from one of these, use _Settings → Themes → Download CSS_ next to it, or download the [starter stylesheet](/styling/starter-stylesheet/).
