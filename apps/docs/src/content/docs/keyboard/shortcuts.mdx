Every command has an entry in the [command palette](/keyboard/palette-and-rebinding/), and most have a shortcut. The shortcut is shown under each command-bar button, next to top-bar buttons, and in menus. All shortcuts can be changed.

This table is generated from MDLeaf's command catalog.
