## What MDLeaf is

MDLeaf is an installable web app for writing Markdown that is laid out like a word-processor document. You type Markdown in a source editor; next to it a live preview shows either a continuous **draft view** or real **pages**. What you see in page view is what you get in the PDF.

<CardGrid>
  <Card title="Real pages" icon="document">
    Page size, orientation and margins come from a profile. Page breaks, running headers and footers, and page numbering are written in the document with a few short directives.
  </Card>
  <Card title="Works offline" icon="laptop">
    After the first visit everything runs without a network: editing, pagination, PDF export, image re-encoding and the built-in fonts.
  </Card>
  <Card title="Keyboard first" icon="seti:config">
    Every command has a shortcut, shown on its button. The command palette finds everything, and every shortcut can be changed.
  </Card>
  <Card title="Portable files" icon="seti:zip">
    Documents, images and their page setup travel together in a single `.mdl` file. In Chromium you can also keep a document in a normal folder on disk.
  </Card>
</CardGrid>
